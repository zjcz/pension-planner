Take control of your pension planning

Pension Planner is a self-hostable web app for tracking your pensions, income sources, and planning for retirement — all under your own control.

Get started View on GitHub

What it does

Built for people who want a clear picture of their retirement outlook without sending their data to a third party.

📈

Pension dashboard

Track multiple pension pots, state pension entitlement, and other income sources in one place.

📝

Audit history

Optional audit trail for your data changes, with a per-user toggle and full change history view.

🚆

Docker & native image

Run via Docker Compose or grab a blazing-fast GraalVM native image from GitHub Packages.

👥

Multi user

Run multiple accounts in a single instance, each with their own securely separated data.

🖥️

Self-hosted

Single Spring Boot JAR serves the API and the UI. SQLite database — no external services required.

🛠️

Modern stack

Java 25 & Spring Boot 3.5 backend, React 19 & TypeScript frontend with a fully tested codebase.

Built with

Get started in minutes

Run the prebuilt image from GitHub Packages, or build from source. Full setup instructions — including IntelliJ and command-line options — are in the README.

Run the published image

The quickest way to get going. Save the following as docker-compose.yml and start it with docker compose up -d. 

services:
  pension-planner:
    image: ghcr.io/zjcz/pension-planner:latest
    container_name: pension-planner
    restart: unless-stopped
    ports:
      - "8080:8080" # host:container — change the host port if 8080 is taken
    environment:
      # Set a fixed secret so logins survive restarts (any long random string)
      - JWT_SECRET=change-me-to-a-long-random-string
    volumes:
      - pension_planner_data:/data # persistent database volume

volumes:
  pension_planner_data:

Then open http://localhost:8080, create an account, and start planning.

Alternatively, run the code

Build and run the full stack from source with Docker Compose. 

git clone https://github.com/zjcz/pension-planner.git
cd pension-planner
docker compose up
